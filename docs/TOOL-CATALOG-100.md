# OfficeTools 100 Catalog

브라우저에서 입력하고 계산·변환·문서 생성 결과를 복사하거나 TXT로 저장하는 업무용 도구 100개입니다. 모든 처리는 외부 API 없이 현재 브라우저에서 수행됩니다.

## 001–015 · 텍스트·문서

글자·단어 수 계산, 대소문자 변환, 공백 정리, 줄 정렬, 중복 제거, 찾기·바꾸기, 이메일·URL 추출, 슬러그 생성, 목록·마크다운 표 변환, 텍스트 차이, 액션 아이템 추출, 변수명 변환, 문서 파일명 생성.

## 016–030 · 회의·커뮤니케이션

회의 안건·회의록·액션 아이템 표·의사결정 로그·후속 메일·상태 업데이트·데일리 스탠드업·주간 보고·임원 요약·1:1 안건·회고 보드·브레인스토밍 브리프·워크숍 진행표·발표 목차·어려운 대화 준비.

## 031–045, 054–055 · 프로젝트·기획

프로젝트 브리프, SMART 목표, 업무 분해 구조, RACI, 리스크 등록부, RAID 로그, 마일스톤, 의존성, 사용자 스토리, 수용 기준, 스프린트 목표, 릴리스 노트, 변경 요청, 범위 영향, 프로젝트 건강도, 집중 업무 계획, 마감 역산.

## 046–053 · 시간·생산성

포모도로 타이머, 날짜 차이, 영업일, 근무시간, 소수시간 변환, 회의 비용, PERT 일정 추정, 업무 우선순위 점수.

## 056–070 · 재무·영업

백분율, 증감률, 할인 가격, 부가세, 마진율, 마크업, 손익분기점, ROI, CAGR, 영업 수수료, 매출 예측, 퍼널 전환율, CAC, LTV, ROAS.

## 071–080 · 데이터·스프레드시트

CSV→JSON, JSON→CSV, JSON 포맷터, CSV 열 추출, 중복 행 제거, 행 정렬, 열 합계·평균, 그룹별 집계, 가중치 점수, 비율 배분.

## 081–090, 099 · 인사·조직

채용공고, 면접 평가표, 구조화 면접 질문, 후보자 비교, 온보딩 체크리스트, 30·60·90일 계획, 성과 리뷰, SBI 피드백, 교육 계획, 연차 잔여 계산, 장애 회고 문서.

## 091–098, 100 · 개발·IT·보안

UUID, 비밀번호 생성·강도 검사, Base64, URL 인코딩, JWT 확인, 정규식 테스트, Unix 타임스탬프, 가동률·허용 장애시간 계산.

## URL 규칙

```text
포털   /Officetools/
도구   /Officetools/tools/<slug>/
사이트맵 /Officetools/sitemap.xml
```

정확한 번호·slug·입력 필드·처리 방식은 `src/catalog.js`에서 관리합니다.
